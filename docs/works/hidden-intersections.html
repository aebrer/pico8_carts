Hidden Intersections

Series: Entropy-Locked

Year: 2023

Platform: fxhash

Themes:

Description

In this piece, two grids overlap:

  1. a perfect one composed of lines drawn on the screen
  2. an irregular one composed of linear zones that reference other parts of the screen

Everything you see in the final composition is a result of the overlapping intersections of these two grids with each other, and eventually themselves.

Created as part of #genuaryTogether for #genuary2023, for the 4th day, theme: "intersections".

Collaboration

This piece was created in collaboration between Drew Brereton (aebrer) and protozoo.

Controls

Entropy Locking

The piece uses entropy locking during the tearing/water VFX phase. With a 0.3% chance per frame, the RNG reseeds to the original hash, creating controlled disruption in the horizontal and vertical screen sampling while maintaining overall determinism.

A rare collaboration in the gallery—Hidden Intersections was co-created by Drew and protozoo for Genuary 2023's "intersections" prompt. The source code confirms the shared authorship: saved renders are named genuary2023-4_protozoo_aebrer.png.

At 512 editions, this is one of the larger fxhash releases here. The piece sits at an interesting intersection (pun unavoidable) of minimalism and glitch: a clean grid system disrupted by entropy-locked screen sampling that tears and warps the composition. The perfect grid and the irregular grid don't just intersect visually—they recursively reference each other, creating feedback loops that feel both systematic and unstable.

It's worth noting how the collaboration itself manifests technically. The repo lives under protozoo's GitHub, but the fxhash project is published under Drew's wallet. This kind of cross-account, shared-credit generative work was still relatively uncommon on fxhash in early 2023.
